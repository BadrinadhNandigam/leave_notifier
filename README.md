# 🏖️ Leave Notifier

A free, installable mobile web app (PWA). When an employee applies for leave, it prepares a WhatsApp alert for all 5 team members, tracks approvals, and rings a leave-day alarm.

## Features
- Apply / approve / reject leave with WhatsApp alerts (wa.me links)
- Leave-day alarm, snooze and phone notifications
- Leave log with filters, CSV copy, Google Calendar reminder
- Works offline, installs to the home screen, no server, no data collection

## Install (users)
Open the app link in your phone browser:
- **Android (Chrome):** ⋮ menu → Add to Home screen / Install app
- **iPhone (Safari):** Share → Add to Home Screen

Link: `https://YOUR-USERNAME.github.io/leave-notifier/`

## Publish on GitHub Pages
1. Create a repository named `leave-notifier` and upload all files in this folder.
2. Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)` → Save.
3. After a minute your app is live at the link above.

## Team members
Edit the `M` list in `index.html` to change names or icons.
